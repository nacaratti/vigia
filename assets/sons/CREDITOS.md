## Aviso de voz

`voz_aviso.wav`: "Atenção! Esta área é monitorada. Você está sendo filmado, e o proprietário já foi avisado."

Gerado com o [Piper](https://github.com/OHF-Voice/piper1-gpl) e a voz [pt_BR faber (medium)](https://huggingface.co/rhasspy/piper-voices/tree/main/pt/pt_BR/faber/medium), cujo repositório é MIT e cujos dados de treino são CC0. A voz foi ajustada a partir do modelo em inglês "lessac", que tem termos de uso próprios. O Piper não é necessário para rodar o Vigia; ele só foi usado para gerar este arquivo.

Para trocar a mensagem, grave a sua no celular e envie pelo painel (Configuração → Sirene → Enviar meu arquivo).
