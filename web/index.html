O Vigia observa as câmeras do seu gravador (DVR/NVR) ou câmeras IP pela rede de casa e avisa quando uma
        pessoa entra nas áreas que você escolher. Cachorros e gatos são ignorados.

      

      

        
        
      

    


    

      

        
Os alertas chegam com foto pelo Telegram, por um robô (bot) só seu. Para criar, leva 1 minuto:

        
    
          
  1. No Telegram, abra o @BotFather e mande /newbot.
    2. 
          
  2. Escolha um nome (ex.: Vigia Casa) e um usuário terminado em bot (ex.: vigia_casa_bot).
    3. 
          
  3. Ele responde com um token (algo como 123456789:AAH...). Cole aqui:
    4. 
        

        

          
          
        

        
O token fica só no arquivo .env deste PC. Quem tiver o token controla o bot: não compartilhe.

Tudo certo! Faltam só os ajustes de cada câmera, na aba Configuração:

      
    
        
  • Zonas: clique na imagem para desenhar a área vigiada (ex.: o quintal, sem a calçada). Sem zona, vale a imagem toda.
    • 
        
  • Horário: por padrão o Vigia arma sozinho das 22:00 às 06:00. Pelo botão no topo (ou pelo Telegram) você arma quando quiser.
    • 
        
  • Sirene (opcional): toca nas caixas de som do PC quando alguém fica na zona.
    • 
        
  • Testar detecção: na aba Ao vivo, passe o mouse sobre uma câmera.
    • 
      

      

        
      

    

  

  
    

    
Procurar câmeras


    
    

      
Gravadores (DVR/NVR) e câmeras IP na rede da sua casa. Funciona com Intelbras, Dahua, Hikvision,
        XMeye e outros com RTSP; se o seu tiver ONVIF, ligue-o no menu de rede dele.

      

      

        
        
      

    


    
    

      

        
        
        
        
      

      
Use o usuário e a senha do gravador (de preferência um usuário só de visualização). Muitos aparelhos
        bloqueiam o usuário após algumas senhas erradas, por isso a busca para no primeiro erro. Os dados ficam só no
        arquivo .env deste PC.
